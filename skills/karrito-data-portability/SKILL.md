# Read and take own data
Use when the user explicitly asks to take their store data out of Karrito. Select the exact authorized store and requested resource, fields, time range and format. If “all my data” is ambiguous, clarify store/resource before bulk collection. Never switch stores on denial or interpret a read grant as permission to export unrelated data or third-party contacts.
Use real available reads: list_my_products/get_product, list_categories/get_category, list_my_orders/get_order, list_customers/get_customer, list_reviews/list_review_requests, get_my_store, get_analytics_report, get_store_team and the redacted connection/webhook reads as appropriate. Inspect current tool schemas for their actual pagination, filters and bounded limits; do not assume every endpoint uses the same query. Advance offsets or returned cursors until the declared total/end, retain stable IDs, and report incomplete pages or permission failures rather than filling gaps. Separate order currencies, exact periods and unavailable metrics.
There is no new whole-account export, ZIP, database dump or automatic CSV endpoint in this skill. Return a structured JSON/CSV-compatible selection or save a local artifact only when an available file tool and the user's explicit request authorize it. Do not promise a download link or cloud export that was not created. Clearly state selected fields and excluded/unavailable data.
Minimize personal information: customers/reviews/orders can contain it; retrieve only requested own data and never collect it to enrich a different store. Credentials, API-key material, invitation links, destination capabilities, webhook payloads and provider response bodies are not exportable through these read tools. Redacted references remain redacted; never reconstruct URLs or query internal storage to bypass the contract. Do not delete or change data after an export unless separately instructed and supported by an authorized workflow. Export tools are available only when your connection lists them; this guide is not an export service by itself.
